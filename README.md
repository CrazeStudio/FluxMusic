# FluxMusic

FluxMusic is an independent Flutter music discovery and streaming client. It uses YouTube Music's public metadata/player endpoints and LRCLIB for lyrics.

## Features
- YouTube Music search with recent searches and metadata cache
- Home discovery cards, popular-search shortcuts, quick picks
- Playback queue, previous/next, seek, shuffle and repeat
- Background audio service and Android media notification controls
- Mini-player and expanded player
- Likes, listening history and local playlists
- Lyrics lookup
- Balanced, high-quality and data-saver stream selection
- Sleep timer, theme preference and offline-search switch
- Local persistence using SharedPreferences

## Android build
Flutter stable and Android SDK are required. The Android project is generated by CI using `flutter create`.

```bash
flutter pub get
flutter create --project-name fluxmusic --org com.crazestudio --platforms android .
flutter analyze
flutter test
flutter build apk --debug
```

APK: `build/app/outputs/flutter-apk/app-debug.apk`

GitHub Actions builds and uploads a debug APK artifact for pushes and pull requests to main.

## Provider limitations
The resolver currently accepts direct audio URLs returned by the YouTube Music player response. Ciphered streams, PO-token gated streams, unavailable tracks and provider anti-bot responses cannot be resolved by this lightweight implementation. No yt-dlp, Python runtime, QuickJS or external extractor is used. Online stream URLs are temporary and cached only briefly.

Equalizer hardware effects and offline audio downloads are not implemented in the Flutter migration. Offline cache mode currently blocks search requests; it does not turn streamed songs into offline files.
